# Calculator 🧮

My first calculator project, built to apply and practice what I learned about **HTML, CSS, and JavaScript**.

## 📌 About the Project

This is a simple calculator project created as part of my journey into web development. The goal was to move beyond tutorials and start applying my knowledge by building something on my own.

## 🛠️ Technologies Used

- **HTML** — To structure the calculator.
- **CSS** — To style the interface and layout.
- **JavaScript** — To implement the calculator's functionality.

## 📚 What I Learned

While building this project, I practiced:

- Creating webpage structures with HTML.
- Styling and positioning elements using CSS.
- Using JavaScript to add interactivity.
- Connecting HTML, CSS, and JavaScript in a project.
- Debugging code and solving problems during development.
- Using Git and GitHub to manage and publish my code.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Rahul-Chaurasiya-Code/Calculator.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
